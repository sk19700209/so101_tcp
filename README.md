# 声で動かすロボットアーム SO-101（ROS 2 × Gazebo × ReazonSpeech）

## 1. 概要

Gazebo 上のロボットアーム **SO-101** を、日本語の音声で操作できるようにした(シミュレーションのみ)。「右」「上げて」「開いて」と話しかけると、手先がその方向に動き、グリッパーが開閉する。

ベースにしたのは、講座サンプルの Qiita 記事「gazeboとROS2を連携してロボットを操作する」。この記事では差動二輪ロボットをキー入力で走らせている。
本課題では対象をアームに置き換え、キー入力の代わりに音声認識 AI で操作するようにした。

| 項目 | 内容 |
| --- | --- |
| OS | Ubuntu 22.04 |
| ROS 2 | Humble |
| シミュレータ | Gazebo |
| AI | ReazonSpeech（日本語音声認識） |
| 言語・主なライブラリ | Python、ikpy、ros_gz |

## 2. 目的

- 両手がふさがっていても、声だけでロボットに指示できる仕組みを作る
- ROS 2 のノード・トピック・launch と、Gazebo とのブリッジの流れを理解する
- 「関節の角度」ではなく「手先の位置」でアームを操作する仕組み（逆運動学）を体験する

## 3. システム構成

```
マイク ─▶ voice_command ─▶ tcp_controller ─▶ parameter_bridge ─▶ Gazebo
          ReazonSpeechで    IKで関節角      Float64 → Double     関節位置制御 ×6
          文字に変換         を計算
          /so101/command  /so101/<関節名>/cmd
```

- `voice_command`：マイク音声から発話の区切りを検出し、ReazonSpeech で文字に変換する。文字の中から「右」「上げ」などの言葉を探し、right・up などの操作コマンドとして送る
- `tcp_controller`：コマンドを受け取り、目標の手先位置から ikpy で関節角を求めて 関節に送る
- `parameter_bridge`：ROS 2 のメッセージを Gazebo のメッセージに変換する（記事と同じ）
- Gazebo：URDF に追加した位置制御プラグインが、受け取った角度に関節を動かす

### 操作方法

| 声で言う例 | 動作 |
| --- | --- |
| 前 / 後ろ | 手先を前 / 後ろへ 3 cm |
| 左 / 右 | 手先を左 / 右へ 3 cm |
| 上げて / 下げて | 手先を上 / 下へ 3 cm |
| 開いて / 閉じて | グリッパーを開く / 閉じる |
| ホーム | ホーム姿勢に戻る |

「前、それから左」のように続けて言うと、順番に実行する。

## 4. 工夫した点

1. **GPU なしで動く軽量な日本語音声認識を選んだ**
   ReazonSpeech の k2 版を、軽量な int8 モデルで CPU 上で動かしている。特別な PC がなくても再現可能。

2. **音声認識とアーム制御をノードで分けた**
   音声ノードは「right」「up」のような短いコマンドを `/so101/command` トピックに送るだけで、アームの計算は別ノードが受け持つ。`ros2 topic pub` で同じコマンドを手で送れば、マイクなしでもアーム側だけ動作確認。

3. **自由な言い回しでも反応するようにした**
   決まった単語だけでなく、「右に動かして」「少し下げて」のような文中からも言葉を拾う。1 回の発話に複数の指示があれば、話した順に実行する。漢字・ひらがなのどちらで認識されても反応する。

4. **逆運動学はライブラリ（ikpy）に任せた**
   URDF を読んで IK を解いてくれる ikpy を使った。手先の位置だけを合わせ、手首の回転は固定にして問題を簡単にした。届かない位置を指示されたときは無視して直前の姿勢を保ち、アームが変な姿勢に飛ぶのを防ぐ。

5. **公式の URDF を流用し、変更は最小限にした**
   SO-101 の公式 URDF（TheRobotStudio/SO-ARM100）をコピーし、次の 3 点だけを書き足した。
   - メッシュのパスを Gazebo が見つけられる形に変更
   - 土台を地面に固定
   - 6 関節分の位置制御プラグインを追加

## 5. 今後の課題

- 「3 センチ右」のように、移動量も声で指定できるようにする
- 手先の向きも指定できるようにする
- カメラと物体認識を加え、「赤い箱をつかんで」のような指示に対応する
